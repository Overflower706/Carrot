Carrot

액션 RTS <캐롯 프로젝트> 출시를 목표로 한 시즌 프로젝트
이 위키는 프로젝트 전반의 흐름을 바깥에서 관리한다. Labs를 제외한 각 프로젝트 내부 문서는 그 프로젝트 자신의 위키가 소유한다.

세 가지

작업 이름위치공개무엇
Carrot ProjectCarrotProject/비공개 액션 RTS. 스팀 출시 목표
Control LabsCarrotProject/ 안의 씬 하나빌드만 배포 3가지 조작으로 아군 NPC와 함께 적군 NPC를 무찌르는 게임 규칙
3가지 조작의 조작감 참고용
Carrot LabsCarrotLabs/저장소까지 공개 상기 두 작업의 일반화 된 형태

Labs 둘 다 목적은 인디 게임 개발 씬에 기여하는 것이다. Control Labs는 저장소가 비공개라 유료 에셋을 그대로 쓰고, Carrot Labs는 공개라 대거 들어낸다.

폴더 구조 

Carrot/                  이 위키의 루트.  저장소 Overflower706/Carrot  (공개)
├─ Wiki/                 지금 읽고 있는 문서들
├─ CarrotProject/        저장소 Overflower706/CarrotProject  (비공개)
│                        └ Control Labs는 이 안의 씬 하나다
└─ CarrotLabs/           저장소 Overflower706/CarrotLabs  (비공개 → 공개 예정)

세 폴더는 각자 별개의 git 저장소다. 하위 둘은 루트 저장소에 올라가지 않는다 — 루트 .gitignore가 허용 목록 방식이라 Wiki/와 CLAUDE.md 외에는 전부 무시한다. 루트가 공개인데 CarrotProject의 구매 에셋이 한 번 딸려가면 되돌릴 수 없기 때문이다.

계획

0. Carrot Project의 개발은 계속한다.

1. Control Labs — 빌드 공개 및 공유

2. Carrot Labs — 저장소 공유

3. Carrot Project — 게임 출시

진행 중인 작업

조작감 비교 기반 프로젝트 분리 계획 (1단계 진행 중)
롤식·엘리스식·세피리아식 셋을 한자리에서 비교하는 웹 빌드를 내고, 그 기반을 공개한다. 히스토리 세탁이 아니라 새 저장소에 필요한 것만 옮긴다(스크립트 약 25개 + 씬 2개). 0단계 완료 — 공개 기반은 CarrotLabs, 기존 비공개는 CarrotProject로 개명.

Carrot Labs의 고정 포맷

2D 사이드뷰 + 육각형 타일 오토배틀러 + 플레이어 캐릭터 + 3가지 조작법 + 당신의 규칙.
하나부터 열까지 고칠 수 있는 자유도는 엔진을 만드는 것과 다르지 않기에 고정할 것은 고정함.
구체적인 각 항목의 정의는 별도로 문단에서 다룹니다.

3가지 조작법
롤식 · 엘리스식 · 세피리아식. 무엇을 고정하고 무엇을 비교하는가.
플레이어 캐릭터
오토배틀러 판 위에 사람이 직접 끼워 넣는 한 명.
NPC
아군과 적군. 사람이 만지지 않아도 알아서 싸우는 쪽.
육각 타일
사이드뷰에서 XY 평면에 서는 판. 이동과 전투가 전부 이 위에서 일어난다.

답이 필요한 것

  • 엘리스식 · 세피리아식 조작 규칙의 확정 범위 — 기획서는 CarrotProject 자신의 위키에 있다. 미확정이면 임의로 정하지 말고 물어본다.
